# 双主题液态玻璃 · Skill 1.3

按 liquid-glass-swiftui 1.3 的 Dual-theme Liquid Glass 方向实现，运行目标为 macOS 26+。

- 保留现有 NavigationSplitView、图标＋文字菜单、工具功能与快捷键。概览卡保持 80 pt，短待办卡保持 68 pt 起，操作目标至少 44 pt。
- 棱镜外观改为珍珠白／墨蓝底色。卡片、侧栏面板、选中菜单项和次按钮使用原生 Glass.clear 与低浓度染色，长文本输入／结果区仍使用稳定的不透明底色。
- 卡片光纹由 SwiftUI 曲线路径绘制，包括细亮芯、较宽的柔光和错位细线。上方白光、左下青光、下沿紫光、少数右下暖光保持统一方向，正文中心安静。
- 不再将同一张蓝金图片重复铺进每张卡片。工具以稳定图标标识、待办以 UUID 改变光带曲率和长度，重排和重启不随机变化。
- 主按钮与选中分段保留深蓝底及白字，次按钮改用通透玻璃和较轻的倒角。装饰层不接收点击，也不进入辅助功能树。
- 指针在卡片内移动时，面部反光跟随，光带最多偏移 1.5 pt；离开时复位。焦点与选中态独立。遵循用户要求，页面、选中项和按钮不执行淡入淡出，也不加入悬停升降或循环动画。
- 减少动态效果冻结指针跟随与按压位移。减少透明度或增强对比度使用实色面并移除光带和反射光池。

窗口使用用户提供的蓝紫→青蓝→蓝金光纹图，保存为 CausticEnvironment.png。深色以 25%、浅色以 5% 浓度显示；侧栏与详情按同一窗口坐标裁切。移除窗口额外的曲线叠加，卡片自身光带仍由代码绘制。打包资源位于 Contents/Resources/LetItGo_DesignSystem.bundle。

主按钮配色测试验证可精确计算的固定渐变。原生玻璃的最终对比度与背景、窗口激活状态有关，静态颜色测试不能代替运行窗口检查。ImageRenderer 静态预览也不完整呈现系统合成的玻璃折射。

此实现是原生材质与自绘光带的组合，并非光线追踪或真正三维折射模拟。
